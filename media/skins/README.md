# Novu crimson skin

`novu-crimson.png` is the flat artwork requested by Novu: red glowing gothic lettering, a crown over the N,
a black circular field and transparency outside the circle. It is a standalone PNG, not an installer or an
automatically applied game mod.

Generated with Codex's built-in image generation tool, using the supplied King skin screenshot as a visual reference.
The output was copied without image processing. This image was also opened in Asset Lab for the README editor capture.

## Generation prompt

Create a finished flat 2D game skin PNG inspired by the supplied reference. A perfectly circular solid near-black disk,
centered, filling about 90% of a square canvas. Outside the disk is fully transparent. Within the disk the ONLY text is
exactly 'Novu', large and clearly legible, custom wicked ornate gothic blackletter, capital N and lowercase ovu.
Bright crimson red letter faces, scarlet highlights, rich deep red bevel-like interior detail rendered as flat graphic
art, refined intense red neon bloom around lettering. A small elegant five-point royal crown in luminous red, tilted
slightly left above the upper-left stroke of the N, unmistakably crowning the N. Beautiful bespoke typographic ligatures
and sharp serifs, balanced as a premium personal game skin. Match the spirit and red glowing lettering of the reference
King skin, but spell Novu. No green background, no game UI, no caption beneath, no King word, no mockup, no perspective,
no 3D ball, no watermark. Crisp silhouette, ample padding to avoid clipping the crown and glow, 1024x1024.

The generator returned a 1254 × 1254 PNG; the original resolution is preserved.
