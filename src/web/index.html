How Mitosis draws its UI
The installed MetalWorks sheet contains up, down, disabled, selected, danger, and call-to-action skins. The shading is painted into these images.
The executable includes Feathers Scale9Image, tintMultiplier, and backgroundColor symbols. The cached shaders include texture × color multiplication. Some colors also come from runtime values, so a texture edit may still be tinted in the game.
